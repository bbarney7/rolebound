# Gather targets

Companies the gatherer polls, grouped by ATS. One slug per line under the matching
heading. Copy this to `targets.md` in the workspace root and edit freely — the
gatherer re-reads it on every `/gather`.

The slug is whatever the company uses in its public board URL:

- Greenhouse — `https://boards.greenhouse.io/<slug>` (also `job-boards.greenhouse.io/<slug>`)
- Ashby — `https://jobs.ashbyhq.com/<slug>`
- Lever — `https://jobs.lever.co/<slug>`

Only public JSON boards are read; nothing here logs in or scrapes HTML.
